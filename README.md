# 남산중 일심동체 챌린지

학교 축제에서 태블릿으로 운영하는 2인용 포즈 협동 게임입니다. 기존 GAS 시작 화면과 GitHub 카메라 화면을 하나의 GitHub Pages 앱으로 통합한 버전입니다.

## 주요 기능

- GitHub Pages 단독 실행(GAS 불필요)
- 전면 카메라에서 두 사람 동시 인식
- 체육·미술·음악 모드별 5개 미션(선택한 교과로 총 5라운드)
- 좌우 참가자용 반투명 포즈 안내선
- 관절 각도에 따른 빨강 → 노랑 → 초록 피드백
- 체육의 역할 분담·방향 반응·2단계 연속 동작 판정
- 미술의 유명 작품 5종 2인 포즈 재현
- 음악의 4박·8박 시각 신호, 연습 1회 후 실제 도전
- 정지 자세를 약 1초 유지하면 자동 판정
- 5라운드 총점 및 기기별 TOP 10
- 학번·이름·사진·영상 서버 저장 없음
- 태블릿 가로 화면과 설치형 웹앱(PWA) 지원

## GitHub Pages 배포

1. GitHub에서 사용할 저장소를 엽니다.
2. 이 폴더 안의 파일과 `assets` 폴더를 저장소 최상위에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택한 뒤 저장합니다.
6. 표시된 `https://사용자명.github.io/저장소명/` 주소로 접속합니다.

카메라는 HTTPS 주소에서만 정상 작동합니다. GitHub 파일 화면의 주소가 아니라 Pages 배포 주소를 사용하세요.

## 현장 권장 설정

- 태블릿을 가로로 고정하고 화면에서 **홈 화면에 추가**를 실행합니다.
- 카메라와 참가자 사이 거리는 약 2.5~3.5m를 권장합니다.
- 두 사람의 머리부터 발끝까지 모두 나오도록 태블릿 높이와 각도를 조절합니다.
- 역광을 피하고 두 사람에게 비슷한 밝기의 조명이 닿게 합니다.
- 앱 최초 실행에는 동작 인식 모델 다운로드를 위해 인터넷 연결이 필요합니다.
- 이후에도 안정적인 운영을 위해 축제 중에는 인터넷 연결을 유지하는 것을 권장합니다.
- 축제 시작 전에 태블릿별로 한 번 실행해 카메라 권한을 허용합니다.

## 점수 기록

점수는 각 태블릿의 브라우저 `localStorage`에만 저장됩니다. 다른 태블릿과 순위를 합치지 않으며, 브라우저 데이터를 삭제하면 기록도 사라집니다. 최고 점수 화면의 **기록 초기화** 버튼으로 TOP 10을 지울 수 있습니다.

## 교과별 미션

- 체육: 균형 듀오 → 릴레이 터치 → 결정적 한 장면 → 패스 앤 슛 → 챔피언의 순간
- 미술: 절규 → 아메리칸 고딕 → 아테네 학당 → 야경 → 아담의 창조
- 음악: 같은 박 → 주고받는 박 → 높고 낮은 멜로디 → 지휘자와 연주자 → 마지막 합주

음악은 한 박을 0.8초로 진행합니다. 화면 상단의 숫자 원이 현재 박자에 맞춰 점등되며, 첫 순환은 연습이고 두 번째 순환만 점수에 반영됩니다.

## 점수 조절

`app.js` 상단의 값을 변경할 수 있습니다.

```js
const ROUNDS_PER_GAME = 5;  // 게임당 라운드 수
const ROUND_SECONDS = 15;   // 라운드 제한 시간
const HOLD_REQUIRED_MS = 950; // 성공 자세 유지 시간
const SEQUENCE_HOLD_MS = 650; // 연속 동작의 단계별 유지 시간
const MUSIC_BEAT_MS = 800;  // 음악 미션 한 박의 길이
const PASS_SCORE = 74;      // 안내선 성공 기준
```

## 개인정보 처리

카메라 프레임은 브라우저 안에서 MediaPipe Pose Landmarker로 분석됩니다. 이 앱의 코드에는 사진·영상·얼굴·학번·이름을 서버로 전송하거나 저장하는 기능이 없습니다.
